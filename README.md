# ☁️ AWS SAA 80/20 Learning Roadmap

> Lộ trình tự học **AWS Solutions Architect Associate** cho .NET Backend Developer.
> Agent-powered · 80/20 · Scaffold-based · Learning Science integrated.

**69 bài · 3 phases · ~20 tuần · Hands-on với AWS Free Tier**

---

## Triết lý

```
Core First → Cert Ready
Làm vững nền móng, chứng chỉ là kết quả tự nhiên.
```

- **80/20**: 20% services tạo 80% giá trị thực tế
- **Scaffold**: Bài sau xây trên bài trước, không nhảy bài
- **.NET Bridge**: Leverage kinh nghiệm .NET để học nhanh hơn
- **Learning Science**: 11 kỹ thuật ghi nhớ dựa trên nghiên cứu khoa học

---

## Cách dùng

### 1. Clone repo

```bash
git clone <repo-url>
cd aws_saa_8020_learning_roadmap
```

### 2. Mở workspace bằng AI Agent

Mở thư mục project trong Antigravity / Gemini workspace.
Rule file tại `.gemini/rules/` sẽ tự động load.

### 3. Bắt đầu học

```
Bạn: "bài 1"
```

Agent sẽ render bài học đầu tiên. Xem [hướng dẫn chi tiết](aws-saa/README.md).
