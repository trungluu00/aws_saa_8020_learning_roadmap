# Phase 3 — Cert Booster: Lesson Map

> **~15 bài · 4-6 tuần**
> Fill gap + Luyện đề → Pass SAA-C03 exam

> [!IMPORTANT]
> Phase 3 CHỈ kích hoạt khi bạn quyết định đi thi.
> Sau Phase 1 + 2, bạn đã có ~70-75% kiến thức cần thiết.
> Phase 3 tập trung vào 25-30% còn lại: services ít dùng nhưng hay ra thi + luyện đề.

| Mục | Chi tiết |
|-----|----------|
| Thời gian | 130 phút |
| Số câu | 65 câu (50 scored, 15 unscored) |
| Đậu | 720/1000 (~72%) |
| Format | Multiple choice + Multiple response |
| Phí | $150 USD |
| Validity | 3 năm |
